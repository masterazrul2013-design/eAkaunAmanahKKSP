# eAkaunAmanah - Sistem Pengurusan Akaun Amanah 🏛️
**Kolej Komuniti Sungai Petani**

Sistem Pengurusan Kewangan & Akaun Amanah berasaskan Web App modern & responsif bagi menguruskan Terimaan Pendapatan, Perbelanjaan, Tuntutan Penceramah Jemputan, Rekod Invois, Sebutharga, Pengurusan Stok (KEW.PS-3), serta Laporan Kewangan Tahunan.

---

## 🌟 Ciri-Ciri Utama Sistem

1. **Dashboard Utama & Analytics**:
   - Ringkasan Baki Kewangan, KPI Terimaan vs Perbelanjaan, Carta Visual Interaktif (Chart.js), dan Butang Tindakan Pantas.

2. **Modul Penyata Tahunan**:
   - Penyata Untung Rugi 12 Bulan dengan pilihan **Tapisan Tahun Kewangan** (2025, 2026, ALL).

3. **Modul Pendapatan & Resit**:
   - Perekodan terimaan yuran, program & sumbangan beserta nombor resit rasmi.

4. **Modul Perbelanjaan & Perolehan**:
   - Penjejakan bayaran pembekal, nombor Pesanan Kerajaan (PO) & status pembayaran.

5. **Modul Tuntutan Penceramah Jemputan**:
   - Perekodan elaun mengajar & status kelulusan penceramah.

6. **Modul Invois & Sebutharga Rasmi**:
   - Tetingkap cetakan dokumen format A4 rasmi lengkap dengan **Logo Rasmi Kolej Komuniti Sungai Petani**, alamat, telefon, jadual item, dan ruangan tandatangan.

7. **Modul Pengurusan Stok (KEW.PS-3)**:
   - Penjejakan kuantiti stok terimaan (Rx) & keluaran (Tx) dengan penunjuk automatik *Stock Discrepancy*.

8. **Pusat Laporan & Eksport**:
   - 8 Modul laporan strategi kewangan dengan sokongan eksport ke **Excel (.xlsx)**, **PDF**, dan **Cetakan A4**.

---

## 🚀 Cara Menjalankan Projek (Local Development)

### 1. Prasyarat
- **Node.js**: Versi 18 atau lebih baru.

### 2. Pemasangan & Menjalankan Dev Server
```bash
# Clone repository
git clone https://github.com/USERNAME/eAkaunAmanah.git
cd eAkaunAmanah

# Install dependencies
npm install

# Jalankan dev server
npm run dev
```

Server tempatan akan dibuka di: `http://127.0.0.1:3000`
